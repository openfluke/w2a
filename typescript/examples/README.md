# Examples for @openfluke/welvet

| File | Run |
|------|-----|
| `consumer_demo.ts` | `npm run test:consumer` — npm install path smoke |
| `run-example-smoke.ts` | `npm run example` — dense + cameral |
| `browser.html` | copied into `dist/` on build; open via `npm run serve` → `/browser.html` |

Chapter-by-chapter npm + HTML demos live in the separate **example** repo (`welvet/*/npm`, `welvet/*/html`, `cam/*/…`) with `WELVET_TS` pointing here.
